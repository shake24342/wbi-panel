wbi 生图控制台

空壳前端：输入 GitHub 令牌后，才可控制云端会话（开始 / 续期 / 停止 / 生图）。所有计算都在云端 Actions 完成，本机无需开机。

① 连接仓库

令牌只存在你本机浏览器（localStorage），不会上传到任何第三方。建议用 fine-grained token，仅授权本仓库的 Contents: RW + Actions: RW。

② 云端会话（点开始 → 跑起来；不续期 → 几分钟后自动关闭）

「开始」= 触发云端 wbi-session 工作流；「续期」= 改写 data/session_renew.json 的过期时间；**到点未续期，云端进程自动退出**（省 Actions 分钟）。

③ 生图

队列 —
「加入队列」写入 data/queue.json，会话跑着时每隔几分钟取一条执行；「立即生图」直接触发 wbi-generate（不依赖会话）。
